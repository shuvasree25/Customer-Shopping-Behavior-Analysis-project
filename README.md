# Customer-Shopping-Behavior-Analysis-project
Customer Shopping Behavior Analysis using Python, SQL, and Power BI to uncover customer spending patterns, product performance, discount usage, subscription behavior, and actionable business insights.
Project Overview:                                                                                                                                                 This project analyzes customer shopping behavior to understand purchasing patterns, customer segments, product performance, subscription behavior, discount usage, and revenue trends. The analysis uses Python (Pandas) for data cleaning and exploratory analysis, PostgreSQL for business-focused SQL analysis, and Power BI for interactive visualization and dashboard reporting.
