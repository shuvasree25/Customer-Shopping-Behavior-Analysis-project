# Customer-Shopping-Behavior-Analysis-project
Customer Shopping Behavior Analysis using Python, SQL, and Power BI to uncover customer spending patterns, product performance, discount usage, subscription behavior, and actionable business insights.
Project Overview:                                                                                                                                                 This project analyzes customer shopping behavior to understand purchasing patterns, customer segments, product performance, subscription behavior, discount usage, and revenue trends. The analysis uses Python (Pandas) for data cleaning and exploratory analysis, PostgreSQL for business-focused SQL analysis, and Power BI for interactive visualization and dashboard reporting.

Key Insights:
- The dataset contains 3,900 customer purchase records across 18 attributes.
- The average purchase amount is approximately $59.76.
- The average customer review rating is approximately 3.75/5.
- Male customers represent approximately 68% of the dataset, while female customers represent 32%.
- Customer behavior was segmented into four age groups to support demographic analysis.
- Purchase frequency categories were converted into day-based values to support more consistent behavioral analysis.
- SQL analysis provides insights into revenue, discounts, products, shipping, subscriptions, customer loyalty, and age-group performance.
- Power BI provides an interactive view of customer and purchase behavior across multiple business dimensions.
